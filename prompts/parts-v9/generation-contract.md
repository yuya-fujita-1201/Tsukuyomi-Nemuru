# character-v9 生成・整列契約

## 変更範囲

- `character-v8` の評価済み正面、自然左右、全身3/4、眼球、母音A/U/E/Oを保持する。
- 母音Iだけを横62×縦29px、中心 `(543, 606.5)` へ置換する。Eの70pxより狭く、白い上歯を明確に残す。
- 正面と既存右向き終点の間に `right-step-25 / 50 / 80` の完成ラスターを追加する。
- 左向きは今回再生成しない。既存 `natural-left / left` を保持する。

## 画像生成入力

中間絵は次の3枚を同時参照する。

1. `character-v8/previews/live2d-neutral-v1.png`: 正面終点
2. `character-v8/poses/view-right-natural-v1.png`: 首中心の自然右終点
3. `character-v8/poses/view-right-3q-v1.png`: 全身3/4右終点

全出力は1086×1448相当、単色クロマキー背景、キャラクター・衣装・髪・月マイク・本ペンダントを維持する。25%は肩をほぼ正面、50%は自然右より手前、80%は自然右より進み全身3/4より手前とする。

採用したImageGen原本は `assets/character-v9/raw/imagegen/` に保存する。ImageGenが1085×1449などを返す場合は、フルキャンバス編集として1086×1448へ直接リサイズしてからクロマキーを除去する。

## 表情差分

各中間絵はニュートラルと「閉じ目＋小開口」を生成する。ランタイム4状態は後者から固定ROIだけを採用して構成する。

| コマ | 目ROI | 口ROI |
|---|---|---|
| right-step-25 | `(406,417)-(735,529)` | `(527,565)-(631,636)` |
| right-step-50 | `(443,414)-(754,527)` | `(568,566)-(663,632)` |
| right-step-80 | `(467,406)-(766,527)` | `(607,571)-(695,628)` |

ROI外はニュートラルとピクセル一致させ、生成編集による髪・衣装・輪郭の差を表情レイヤーへ持ち込まない。

## ランタイム順序

- 右首: `front → right-step-25 → right-step-50 → natural-right`
- 右体: `front → right-step-25 → right-step-50 → natural-right → right-step-80 → right`
- 逆方向は上記を逆順に通る。
- 左右をまたぐ要求は正面へ戻してから反対側へ進む。

隣接コマは既存の完全閉眼ワイプで交換し、半透明クロスフェードによる髪・輪郭の二重像を避ける。

## 再構築

```bash
.venv/bin/python scripts/build_character_v9.py
```

生成物には、右向き6段階一覧とI口の修正前後比較も含める。
