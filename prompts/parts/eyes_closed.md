# ImageGen Prompt: eyes_closed

Generate exactly one 1086×1448 full-canvas part containing only both closed
eyelids and eyelashes for Tsukuyomi Nemuri.

- relaxed downward-curving closed-eye arcs
- elegant lavender-brown upper lashes
- a few fine outer lash tips on both sides
- subtle pale-lavender eyelid crease shading
- calm natural blink, not a smiling crescent or exaggerated expression

This layer replaces the full open-eye stack during a blink, so it must not
contain sclera, irises, pupils, catchlights, eyebrows, skin, or hair.

Coordinate contract:

- viewer-left closed eye / character-right: approximately x=425..520,
  y=378..425
- viewer-right closed eye / character-left: approximately x=565..660,
  y=378..425

Every non-target pixel must be perfectly flat `#00FF00`.
