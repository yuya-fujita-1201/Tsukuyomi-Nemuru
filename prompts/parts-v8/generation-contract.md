# character-v8 生成・整列契約

## 変更範囲

`character-v7` の正面ベース、分離眼球、自然左右、全身3/4をpixel-exactで保持し、
正面専用の中開き母音口 `mouth_vowel_a/i/u/e/o` だけを追加する。

## 画像生成条件

- 入力参照: `assets/character-v7/parts/aligned-v1/mouth_open_small.png`
- 出力: 口だけを描いた1086×1448全キャンバス
- 背景: 単色 `#00FF00`。影、勾配、テクスチャ、発光なし
- 禁止: 顔、肌、鼻、顎、文字、ラベル、別パーツ
- 線: 細い暗藤色。中央に控えめなピンクのリップ色を残す
- 開き: 最大開口ではなく静かな発話の中開き

## 整列先

すべて鼻中心と同じ `x=543`、既存口中心 `y=606.5` 付近へ合わせる。

| 母音 | target bbox | 意図 |
|---|---|---|
| あ | `(510, 585, 576, 629)` | 縦に開く中型の楕円 |
| い | `(505, 594, 581, 618)` | 横長で浅い開口 |
| う | `(521, 592, 565, 622)` | 小さく丸めた開口 |
| え | `(508, 590, 578, 623)` | いより縦に開く横長口 |
| お | `(518, 587, 568, 627)` | うより大きい丸型口 |

透過はImageGenスキルの `remove_chroma_key.py` を使い、生成物のalpha bboxを切り出して
上記bboxへLanczos整列する。再構築は `scripts/build_character_v8.py` で行う。

## ランタイム条件

- 母音手動選択時は `mouthOpen=0.50`
- 選択母音1枚だけを表示し、`mouth_open_wide` は使わない
- 自動発話時は従来の閉口／小開口／大開口ウェイトへ戻す
- 母音素材は正面専用。自然左右・全身3/4では既存小開口差分へ安全に写像する

## 髪と向き

平面化された正面絵から髪だけを切り抜いても、肩・服・身体の隠し塗りは復元できない。
そのため `parameter` では髪／身体メッシュ変形を停止し、`headTurn` は自然左右完成カット、
`turn` は全身3/4完成カットを選ぶ。髪の独立物理は、隠し塗りを含む再生成素材が揃うまで保留。
