# Webパラメータレビュー仕様（character-v14）

## 起動

```bash
npm run dev
```

初期状態はAI演技を停止した `連続首・体キー実験室（推奨）`。スライダー操作は描画目標へ
即時反映され、共有URLだけを90msデバウンスして書き換える。

## 主要パラメータ

| パラメータ | 範囲 | 連動先 |
|---|---:|---|
| `headTurn` | -1〜1 | 左右16キーの首系列。60fps換算12フレームで90%以上追従 |
| `turn` | -1〜1 | 左右16キーの体系列。左右3/4の評価済み絵を終点に保持 |
| `gazeX` | -1〜1 | 正面は左右最大12px、横向きは左右最大5px移動 |
| `gazeY` | -1〜1 | 正面は上下最大7px、横向きは上下最大2px移動 |
| `mouthOpen` | 0〜1 | 正面4段階口。横向きは閉じ口〜小開口 |
| `blink` | 0〜1 | 正面・横向きの開眼／閉眼 |

斜め視線は単位円へ正規化し、目の可動域内に留める。

## 向きモーション

- `parameter`: `headTurn` と `turn` を別々に操作。`turn` が動いている間は体系列を優先
- `natural`: `turn` で首16キーを操作
- `full`: `turn` で体16キーを操作。既存左右3/4は±1の終点
- `soft`: 旧・正面ベースの控えめなメッシュ変形（比較用）
- `head-only`: 旧・正面ベースの大きめのメッシュ変形（比較用）

首・体とも `abs(value) × 15` をキー位置とし、移動中は前後2キーを連続表示する。目標角へ到達して
80ms静止すると最寄りの単一キーへ固定し、横向き全体のidle/breath変形も止める。入力再開時は
1フレーム目で固定を解除する。旧来の閾値カット、
強制瞬き、曲線ワイプは使わない。左体は33%・66%の専用アンカーを追加し、右は既存の
25%・50%・80%を含めている。

## 横向き追従

首系列と体系列の全64フレームに、旧虹彩を覆うlossless clean eye-base、参照画像から再描画した
dark / luminous可動虹彩、固定上まつ毛、閉眼、小開口パッチがある。横向きの描画順は
`eye-base → shifted iris → fixed eye-line`。中央視線からclean splitを常時表示し、neutral眼との
半透明切替は行わない。そのため中間角度と左右終点でも `gazeX / gazeY / blink / mouthOpen` が動き、
視線移動開始時の旧虹彩縁や可動まつ毛を出さない。画面右＝キャラクター左眼の白い月輪は全右向き
フレームで維持する。横向き口は静かな小開口までで、大開口と母音別口形は未制作。

## 母音の形

正面では `自動 / あ / い / う / え / お` を選べる。母音ボタンは `mouthOpen=0.50` を設定し、
最大開口より小さい専用素材を表示する。A/U/E/Oは現状維持。I / いは今回のサンプルを基準に、
52×15pxの浅いピンク口へ更新し、歯面と黒い口腔は入れていない。

## 詳細パラメータ

`headX`、`headY`、`headTilt`、`breath`、`shoulderSway`、`handAccent`、`bookBob`、
`smile`、`speech` を折りたたみ欄から操作できる。

## URL共有

`variant`、選択母音、デフォルト以外のパラメータをURLへ保存する。`URLをコピー` は待たずに
現在値を書き込み、同じURLを開くとAI演技を停止した状態で復元する。

```text
?variant=parameter&headTurn=-0.62&turn=0.25&gazeX=0.44&gazeY=0.20&mouthOpen=0.35
```

## 現在の制約

- 体系列を表示中は `headTurn` を同時合成せず、体角を優先する
- 16キーは光学補間キャッシュで、CubismのArtMeshやデフォーマではない
- 動作中は隣接ラスターを補間するため軟化し得るが、停止後は単一ラスターへ固定する
- 髪はキー内の描画ごと動くが、髪束別物理は未実装
- PSDのCubism読み込み、ArtMesh、パラメータ、物理演算は未確認
