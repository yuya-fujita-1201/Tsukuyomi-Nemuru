# 本番用アセット計画

> 履歴資料。元画像の構図を維持して切り分けるこの案は不採用となり、現在は [regeneration-plan.md](regeneration-plan.md) の新規再生成方式を採用している。

## 元画像の評価

- 1086×1448、RGB、背景込み、アルファなし
- バストアップとして顔、肩、胸、本、両手、マイクが見える
- 前髪と顔、長髪と肩、右手と本、左手とケーブル、マイクと胴体が重なる
- 単純な切り抜きでは、隠れている額、肩、服、髪、手、本、背景を復元できない

したがって、細かい全パーツの切り抜きから始めない。大きなまとまりを再生成して外観を揃え、独立可動が必要な箇所だけ細分化する。

左右名 `_l` / `_r` はキャラクター基準。画面左の指差し手はキャラクター右なので `arm_r_gesture` とする。

## P2: 必要な場合だけ

- `mouth_inner`, `teeth`, `tongue`
- 母音別の口形
- 指一本ずつ
- 細い髪束
- 服の小リボン、編み目、装飾
- 本の表紙、ページ、背表紙
- マイクの左右耳、本体、スタンド、ケーブルの個別分割

動画で差が見えない細分化は行わない。

## 効率化した制作順

1. `bg_clean` と、透過したバストアップ人物の大きな一枚を作る
2. 「頭髪」「顔」「上半身と服」「両腕と手」「本」の大きなまとまりを同じ基準画像から再生成する
3. 顔から目と口を消した `face_base` を作る
4. 目と口は小さい差分セットとして作る
5. 指差し手だけを袖込みで独立させる
6. 合成プレビューで破綻した群だけ再生成する
7. 座標がずれる場合は、粗いガイドPNGのバウンディングボックスへ `fit` で戻す
8. P0で動画評価し、P1/P2は評価結果に応じて追加する

生成AIへは1回に1パーツを要求し、同じキャンバスサイズ・同じ座標・単色クロマキー背景・隠し塗り範囲を明記する。小パーツを大量に独立生成すると絵柄と座標が崩れやすいため、最初は大きなまとまりを優先する。

## 品質ゲート

- 頭傾き±5度、体揺れ±3度、上下8pxで穴や二重輪郭が出ない
- 前髪、横髪、肩、袖口に十分な隠し塗りがある
- マイクの前後関係が固定される
- まばたきで白目や虹彩が残らない
- 口形切替時に元の口や肌色の縁が残らない
- 本と保持手が離れない
- 原寸合成で顔、髪色、線幅、光源方向が一致する
- アルファ境界に紫、白、背景色のフリンジがない

Cubismへ渡す場合は、PNGをフルキャンバスで統一し、下から上の順でmanifestを作り、プレビュー、レイヤー検証、PSD組立の順で確認する。

## 最大リスク

マイク裏の肩と本、保持手の下の表紙、前髪下の顔、肩と本に隠れた長髪は元画像に存在しない。ここは切り抜きでは解決せず、再生成または手描き補完が必要。
